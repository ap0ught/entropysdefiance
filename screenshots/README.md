# Screenshots Directory

This directory contains screenshots of the Entropy's Defiance app used in the project README and documentation.

## Naming Convention

Please use the following naming convention for screenshots:
- `screenshot_home_screen.png` - Main home screen view
- `screenshot_app_drawer.png` - App drawer view
- `screenshot_task_management.png` - Task management interface
- `screenshot_calendar_view.png` - Calendar integration view
- `screenshot_settings.png` - Settings screen

## Adding Screenshots

When adding new screenshots:
1. Use a clear example that demonstrates the feature
2. Capture in both light and dark themes if applicable
3. Use a 9:16 aspect ratio (standard mobile screen)
4. Keep file sizes reasonable (compress if necessary)
5. Update the main README.md with references to new screenshots
